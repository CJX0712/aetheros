# ADR-006: 图标库锁定 Tabler Icons（P0）

## Status: Accepted (2026-09-19) —— **改判自 Lucide**

## Background

P0 绝对规则要求：Spec 必须锁定**一套** SVG 图标库，禁止 emoji 作为功能图标，禁止混用。

初版锁定 **Lucide 1.46.0**（ISC，1600+ 图标）。设计侧提出异议后复核并**改判为 Tabler**。

改判的决定性理由（功能性，非审美偏好）：
> **Lucide 只有 outline，没有 filled 变体。** UI 的 active / selected 态需要 filled；缺了它就必须引入第二套图标，反而直接违反 P0「只锁一套」。

其余两条为次要理由：
- Tabler 为 MIT（Lucide 为 ISC，两者同为宽松许可，但 MIT 对开源项目更常规）
- Tabler 6184 枚 vs Lucide 1600+ 枚，覆盖面更大，降低"某个语义槽找不到图标"而破例的概率

## Decision

**锁定 Tabler Icons 3.46.0（GitHub Release，2026-07-28）。**

核实数据（github.com/tabler/tabler-icons）：
- MIT 许可
- 6184 枚：**outline 5130 + filled 1054**
- 24×24 网格 / 2px stroke / currentColor
- `@tabler/icons-react`：ESM 逐图标组件，官方称完全 tree-shakable，自带 TS 声明
- `@tabler/icons`：原始 SVG + 元数据（构建期输入）
- 所有 `@tabler/*` 包**共享同一版本号**，不得混版本

### 硬约束（P0，违反退回）

1. 全项目**唯一**图标源。禁止混用第二套；品牌 logo 例外走 simple-icons
2. **禁止任何 emoji 作为功能图标**（含 ❌ ✅ ⚠️ 🔍 之类）
3. 尺寸只有 **16 / 20 / 24** 三档，由 `AppIcon` 包装组件在类型层收口
4. **filled 变体仅用于 active / selected 态**，不得用于装饰
5. **禁 webfont 版**（`@tabler/icons-webfont`）—— 图标字体违背干净 SVG 渲染
6. **禁止 barrel 导入与深路径导入**，只准具名导入
7. **禁止 CDN** —— 图标 100% 打包进产物，零外网请求
8. **`brain` / `sparkles` 及同类「AI 模板味」图标一律禁用**；本地推理一律用 `cpu` 语义图标

### 命名规则
源文件 kebab-case → `Icon{PascalCase}`（`brand-github` → `IconBrandGithub`）；filled 后缀 `Filled`（`IconBrandGithubFilled`）。

## Consequences

**正面**
- filled 变体使 active 态表达无需第二套图标
- 6184 枚覆盖面，语义槽缺失风险低
- MIT 许可，vendored / 再分发无顾虑

**负面**
- **filled 覆盖率仅约 20%（1054 / 5130）** —— 大部分语义槽没有 filled 孪生，"active 用 filled"不能统一套用，需设计侧定兜底规则（无 filled 时用主色切换或 stroke 加粗表达 active）
- 包体积大于 Lucide，依赖 tree-shaking 生效
- 设计侧已按 Lucide 出的稿需重做（一次性成本）

**已知待办**：designer 需提供 Tabler 重键后的图标语义清单，经 ADR-014 的 CI 门禁校验后方可冻结。
